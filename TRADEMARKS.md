# Name and logo

The code is open source under the AGPL. The name "Babillard", the logo, and the app icon are not part of that licence.

You can say your project is based on Babillard, and you can link to it. If you run or publish a modified version, give it a different name and icon, so nobody mistakes it for the real app or thinks we run it. The same goes for app store listings, domains, and social accounts.

Questions go to privacy@babillard.app.
